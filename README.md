# Supervised Learning Algorithms From Scratch: KNN and NaiveBayes
The purpose of this assignment was to apply both the Naïve Bayes classifier and the K-Nearest Neighbors classifier to the digits and breast cancer datasets. K-nearest neighbors is a supervised machine learning method that classifies and predicts data points based on how its closest neighboring data points are labeled. Naïve Bayes is also a supervised machine learning method that uses probability and Bayes’ Theorem to predict the category of a data point.

The implementation includes accuracy scoring and confusion matrices.
